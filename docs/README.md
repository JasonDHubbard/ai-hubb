# Edmonton Business Listings Dashboard

This directory contains the self-contained Edmonton business-for-sale listings dashboard.

## Data Source

Listing data is maintained on Google Drive by the Business Finder agent.

## Updates

To rebuild the dashboard with updated listings, replace `docs/index.html` with the newly generated dashboard file from the Business List Dashboarder agent.
